# R8鳩祭紹介サイト

## 概要
学校の文化祭「R8鳩祭」を紹介するWebサイトです。

## 機能
- 鳩祭の概要・日程紹介
- イベント・企画情報
- 参加団体一覧
- アクセス情報

## 技術スタック
- HTML
- CSS
- JavaScript

## セットアップ
このリポジトリをクローンして、ブラウザで`index.html`を開いてください。

```bash
git clone <repository-url>
cd R8鳩祭紹介サイト
```

## 使用方法
ローカルサーバーで実行するか、`index.html`をブラウザで直接開いてください。

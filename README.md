# 第70回 屋代高校 鳩祭 公式ウェブサイト

第70回屋代高校鳩祭（2026年度開催）の公式ウェブサイトのフロントエンドソースコードリポジトリです。
伝統ある文化祭の魅力を伝えるモダンなビジュアル、アクセシビリティ、そして快適な操作性を追求したインタラクティブな設計を行っています。

---

## 特徴 (Features)

* **デザインシステム**
    * 深みのあるブルーグレー（`#2C3A4E`）と、新緑のオリーブ黄緑（`#8DAE4B`）を基調とした、自然でありながら高級感のあるカラーパレット。
* **躍動感のある高機能アニメーション (`Anime.js`)**
    * スクロールに連動したスマートなスタガーフェードイン。
    * スマホメニューでの気持ちのいいバウンス（弾む）インタラクション。
    * 画面サイズや文字数に応じて自動で高さが伸縮し、文字が見切れないアコーディオンUI。
* **インテリジェント・レスポンシブ**
    * `<picture>` タグによるPC用/スマホ用画像の自動最適化（比率を崩さず美しいシャドウと角丸で配置）。
    * FlexboxおよびCSS Gridを活用した、あらゆるデバイス（PC・タブレット・スマホ）で崩れないレイアウト。
* **外部APIとのシームレスな連携**
    * `Open-Meteo API` を活用し、屋代高校周辺のリアルタイムな天気・気温情報を取得・表示するユーザーファーストな設計。

---

## 画面構成 (Pages)

本プロジェクトは、以下の10の独立した画面コンポーネントで構成されています。

* `index.html` : **総合トップページ**（ヒーロー、ニュース概要、フェスティバルハイライト、開催情報、協賛枠等）
* `about.html` : **鳩祭について**（テーマ「SPARK」の紹介、実行委員長挨拶など、文字のパラパラ表示演出付き）
* `news.html` : **お知らせ・ニュース**（重要ピン留め機能、カテゴリフィルター、キーワード検索、自動改行アコーディオン）
* `club_activity.html` : **部活動等の企画・展示紹介**（文化部や委員会による展示・出店を洗練されたリストで紹介）
* `exhibit.html` : **クラス・班企画一覧**（各クラスの趣向を凝らした企画をカード型UIとインタラクティブモーダルで表示）
* `timetable.html` : **タイムテーブル**（各日程のステージスケジュール等をAnime.jsによるスムーズなタブ切り替えで表示）
* `map.html` : **校舎マップ**（インタラクティブSVGマップ ＆ タップで下からスッと競り上がるドラッグ制御付きボトムシート）
* `events.html` : **本部・実行委員会企画**（特設ステージ企画や全体イベントをわかりやすくカード化）
* `faq.html` : **よくある質問**（カテゴリタブによる高速な表示切り替えとアコーディオンUIを搭載）
* `access.html` : **アクセス**（交通手段、Google Mapの埋め込み、および周辺のリアルタイム天気情報表示機能）

├── map.html                    # 校舎マップページ
